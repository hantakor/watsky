# تطبيق Watsky للجوال (أندرويد وآيفون)

تطبيق ويب متقدم (PWA): تنشره مرة واحدة على الإنترنت مجاناً، ثم يثبّته أي شخص على شاشة جواله فيعمل كتطبيق عادي بأيقونة وبدون شريط المتصفح.

## المحتويات
- `index.html` : التطبيق نفسه
- `api/chat.js` : دالة صغيرة على الخادم تخفي مفتاح الذكاء وتمرّر الرسائل (تدعم Gemini المجاني وClaude)
- `manifest.webmanifest` و `sw.js` و `icons/` : ما يجعله قابلاً للتثبيت كتطبيق

## الخطوة 1: مفتاح Gemini المجاني
1. ادخل إلى aistudio.google.com بحساب Google.
2. اضغط Get API key ثم Create API key، وانسخ المفتاح. لا يطلب بطاقة دفع.
3. المستوى المجاني له حدود على عدد الرسائل في الدقيقة واليوم. وقد تُستخدم الطلبات في المستوى المجاني لتحسين منتجات Google، فلا تكتب أسراراً شخصية في المحادثات.

## الخطوة 2: رفع الملفات إلى GitHub
1. أنشئ حساباً في github.com ثم مستودعاً جديداً باسم watsky (Public).
2. من Add file ثم Upload files، اسحب كل محتويات هذا المجلد (بما فيها api و icons) ثم Commit changes.

## الخطوة 3: النشر على Vercel (مجاني)
1. ادخل إلى vercel.com وسجّل بحساب GitHub.
2. Add New ثم Project، واختر watsky ثم Import.
3. قبل Deploy افتح Environment Variables وأضف:
   - `GEMINI_API_KEY` وقيمته مفتاح Gemini.
   - `APP_CODE` وقيمته رمز سري من اختيارك (يحميك من الغرباء).
4. اضغط Deploy، وسيعطيك رابطاً مثل watsky.vercel.app.

## الخطوة 4: التثبيت على الجوال
- **آيفون:** Safari ثم زر المشاركة ثم Add to Home Screen.
- **أندرويد:** Chrome ثم ⋮ ثم Install app. ولملف APK استخدم pwabuilder.com مع رابط تطبيقك.

عند أول رسالة اكتب رمز APP_CODE وسيُحفظ على جوالك.

## إن توقف الرد لاحقاً
- ظهور رسالة "تعذّر الرد": قد تكون وصلت لحد المستوى المجاني، انتظر دقيقة أو عدة ساعات.
- إن غيّرت Google أسماء النماذج: أضف في Vercel المتغير `GEMINI_MODEL` (للردود السريعة) و `GEMINI_MODEL_SMART` (للردود الأعمق) بالاسم الجديد من صفحة النماذج في aistudio.google.com، ثم أعد النشر (Redeploy).
- لاستخدام Claude بدلاً منه (مدفوع) أضف `ANTHROPIC_API_KEY` وأزل `GEMINI_API_KEY`.
